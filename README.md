# Golden Face — site

Site de apresentação do Golden Face Recognitions, adaptação do projeto [Real-Time Face Recognition Android](https://github.com/atharvakale31/Real-Time_Face_Recognition_Android), de Atharva Kale e colaboradores. Ideias, orientação e testes: Alex Pereira Franco. Modificações: Toqi (IA), em colaboração com Alex.

O site é estático: abra `index.html` com `estilo.css` e as capturas na mesma pasta. As capturas foram recortadas para retirar detalhes desnecessários; não comprovam o funcionamento dos recursos. Este repositório não contém o aplicativo nem o modelo.

O [repositório do aplicativo](https://github.com/NinoNinja13/Golden-Face-Recognition) apresenta o estado atual, incluindo uma pré-release. A equivalência entre o APK e o código reconstruído não foi comprovada; a origem e os termos dos pesos do modelo ainda estão em verificação.
